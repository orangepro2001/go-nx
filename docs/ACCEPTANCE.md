## 2. 自更新（internal/update）

已被单测覆盖：签名被他钥拒绝、下载被篡改丢弃、替换失败回滚、覆盖陈旧 `.old`、强制更新、`dev` 版本被拒、内置公钥可解析。

## 4. 已知缺陷与风险

见 [`IMPLEMENTED.md`](IMPLEMENTED.md) 的安全与会话表；修复排期见各阶段交接文档。当前最重要的几条：认证默认关闭且无法撤销设备、凭据明文、客户端对恶意主机无上限保护、`Grab` 出错即结束会话、退出时不释放输入、按键发送顺序不确定。
